# AGENTS.md

This repository stores release artifacts for ATITD tile caches.

## Purpose
- Host versioned `.tar.gz` tile cache release assets.
- Keep large tile artifacts out of the main `AtitdScripts` repository.

## Rules
- Do not commit tile binaries directly to git history.
- Publish tile archives as GitHub Release assets.
- Keep repository text-only metadata, docs, and governance files.
- Use pull requests for changes whenever practical.
