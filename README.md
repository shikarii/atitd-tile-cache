# atitd-tile-cache

Public release-asset repository for ATITD map tile caches.

## Release asset contract

- Asset name: `tile_cache_<tale>.tar.gz` (default)
- Archive layout: `<tale>/<z>/<x>/<y>.png|webp`

This repository should remain small and text-only in git history. Tile payloads
belong in GitHub Releases, not regular commits.
